# Learning Next.js

A demo project for learning Next.js fundamentals, built lesson by lesson.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Running Tests

```bash
npm test
```

## Lessons

| Lesson | Topic | Route |
|--------|-------|-------|
| 1 | Routing & Navigation | `/`, `/about`, `/blog`, `/products` |
| 2 | Components & Styling | `/components-demo`, `/styling-demo` |
| 3 | State Management | `/state-demo` |
| 4 | Forms | `/forms-demo` |
| 5 | Connecting to the Backend | `/backend-demo` |
| 6 | Global State Management | `/global-state-demo` |
| 7 | API Routes | `/api-demo` |
| 8 | Authentication | `/auth-demo` |
| 9 | Unit Testing | `/unit-testing-demo` |
| 10 | CI/CD | `/cicd-demo` |

## Tech Stack

- [Next.js 16](https://nextjs.org) — React framework
- [TypeScript](https://www.typescriptlang.org) — type safety
- [Tailwind CSS 4](https://tailwindcss.com) — styling
- [Prisma](https://www.prisma.io) — database ORM
- [Zustand](https://zustand-demo.pmnd.rs) — global state
- [React Hook Form](https://react-hook-form.com) + [Zod](https://zod.dev) — forms & validation
- [TanStack Query](https://tanstack.com/query) — data fetching
- [Vitest](https://vitest.dev) + [Testing Library](https://testing-library.com) — unit testing
